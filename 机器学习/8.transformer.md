# Transformer

## tokenization
基于 token 表把输入的内容转成 token

## embedding
1.语义转向量：把 token 转成向量， token 是独立的符号，但是向量之间是有关联的。embedding 是基于 embedding 表直接赋值的，embedding 表是训练得来的。token 转 embedding 就把语义用向量表示出来。
2.位置转向量：给不同的位置设置一个向量，加到语义向量上。位置 embedding 表可以人为设置也可以训练得到。
3.考虑上下文：通过 attention 机制，得到最终的向量

## transformer block 
muti-head attention 加 feedforward 就是一个 transformer block。

### residual stream（残差连接）
每个子层（attention / feedforward）的输出会加上它的输入，再传给下一层：
```
output = x + SubLayer(x)
```
可以把整个 transformer 想象成一条"主干流"（residual stream），每个子层只是往这条流上"叠加"修改，而不是完全覆盖。这样做的好处：
- 梯度可以沿着主干流直接回传，不会消失，使深层训练成为可能
- 每一层只需要学"在原来基础上改什么"，而不是从头学完整表示

## 输出层
transformer block 输出的向量经过：
1. Linear 层：把向量映射到词表大小的维度，得到每个 token 的分数（logits）
2. Softmax：把分数转成概率分布，选出下一个 token

## 推理流程（自回归生成）
本质是文字接龙：
1. 输入一段话，经过整个模型，输出下一个 token
2. 把新 token 拼到输入末尾，整段再输入模型，算出再下一个 token
3. 重复直到输出结束符（EOS）或达到长度上限

因为每次只新增一个 token，之前 token 的 attention 中的 K 和 V 不会变，所以可以用
 **KV Cache**：
- 把每一层算过的 K、V 向量缓存起来
- 下次只需要算新 token 的 Q、K、V，然后和缓存的 K、V 拼接做 attention
- 这样每步从 O(n²) 降到 O(n)，大幅加速推理
