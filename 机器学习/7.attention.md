# Attention

对于输入的两个向量，通过一个 function 输出一个分数 attention weight，function 的参数是通过训练得到。最终 token 对应的向量是当前向量加 attention weight 与其他向量的加权求和。

## self-attention vs cross-attention

attention 的核心操作：用 Q 去查 K 算相关性分数，然后对 V 加权求和。

- **Self-Attention**：Q、K、V 都来自同一个序列。一句话里的每个 token 关注同一句话里的所有 token，目的是让每个 token 的表示融入上下文语义。GPT 用的就是 self-attention。
- **Cross-Attention**：Q 来自序列 A，K 和 V 来自序列 B。用于让一个序列去"查询"另一个序列的信息。典型场景：翻译时解码器（生成目标语言）用 Q 去关注编码器（源语言）的 K、V，从而知道该翻译哪部分。

## causal attention

向量求和的时候，只考虑当前向量之前的向量，不考虑之后的向量。

## multi-head attention

考虑多种关联性，需要多个 attention 模组，每个模组对应一种关联性。

## feed forward

输入多组 attention 模组输出的结果，输出最终的整合结果。feed forward 里面的参数是通过训练得来的。
